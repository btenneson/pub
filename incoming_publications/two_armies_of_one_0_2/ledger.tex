T2. Fixed route: conditional pass. A continuing fair Probe meets one fixed checked Scout route at L iff
    H ⊢ L (with matching/provenance compatibility). The failure model H = {p, p → t, q → t}, L = q, is correct.
T3. Changing route: conditional pass. A finite witness satisfying computable Adm is eventually detected if
    both full proof-certificate enumerations and matching are fair, records persist, and the run continues. This is
    not a before-first-settlement theorem.
T4. Target-free cut: conditional pass. The finite witness filter is decidable when given fully expanded
    certificates. A selected proper DAG node with target-free proof ancestry supplies a witness via splicing. A
    target-free cut may still be irrelevant, and neither universal existence nor speedup is asserted.
T5. Finite obligations: conditional pass. All used open labels of a selected finite conditional proof may be
    discharged by compatible finite H-proofs; the antichain statement is relative to one finite compatible family.
