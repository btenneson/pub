# The MAPQUEST Trilogy

**Brian Tenneson — September 2026**

This folder publishes the three MAPQUEST papers as one connected research trilogy on verifier-gated automated theorem proving.

**Part I — Navigate → Part II — Do not lose a finite proof → Part III — Certify the target**

**When Reaching T Becomes a Verified Proof — The Logical Climax of the Hilbert–Tenneson MAPQUEST Program**
